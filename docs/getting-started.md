# Getting Started with DocuMark

Welcome to **DocuMark** — a lightweight documentation platform.

## Why I Built This

Instead of scrolling social media, I wanted to build something useful for writers.

So I built DocuMark — a simple platform where:

- Articles are written in Markdown
- Drafts can be created easily
- Documentation can be published cleanly

## What You Can Do

Right now the platform supports:

- Markdown writing
- Article preview
- Publishing documentation
- Viewing articles in a documentation site

More features are coming soon 🚀

## Future Plans

Some things I want to add:

- Article search
- Categories
- API documentation templates
- Versioned docs
